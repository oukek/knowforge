## 从具体问题认识训练与推理

训练利用数据调整模型参数，推理使用已有参数对新输入计算结果。二者可能运行同一类网络，但资源消耗、数据流与目标不同。应用调用一次模型 API，通常属于推理，并不会自动训练出一个专属新模型。

以最简单的直线预测 y≈wx 为例，训练要根据样本误差修改 w；推理则在 w 固定后，给定 x 计算预测值。这个小例子能帮助理解损失和梯度。

## 一次参数更新为什么朝某个方向走

损失函数把预测与目标的差异转成可优化数值。例如平方误差衡量偏差大小，梯度表示参数微小变化会怎样影响损失。梯度下降沿减少损失的方向更新，学习率决定步幅；步子过大可能越过较好区域，过小则收敛缓慢。

神经网络通过反向传播计算各参数梯度，优化器据此更新。批次把多个样本的贡献组合起来，训练还可能涉及正则化、学习率调度与数值稳定处理。训练损失下降只说明对所见目标更拟合，不保证新数据上的业务效果同步提升。

因此需要训练集、验证集与测试集的职责区分，避免把测试答案用于调参造成泄漏。推理时也会受输入分布、解码方式与部署精度影响。评估应观察任务指标与失败切片，不能只用一个训练 loss 解释所有产品表现。

## 训练和推理的责任不同

训练根据样本、目标和损失调整参数；推理在给定参数和输入下计算结果。推理时读入新文档或多轮对话，通常只是改变上下文，不等于权重被训练。是否记录用户数据、是否用于后续训练，是服务与产品策略，不能从一次聊天表现推断。

参数是可学习数值，超参数是学习率、批次大小等人为配置；模型状态还可能包含缓存与优化器信息。保存一份聊天 JSON 不等于保存训练 checkpoint，保存权重也不一定包含继续训练所需的全部状态。

## 损失和梯度如何连接

用最小模型 `y_hat = w*x`，单样本平方损失 `(w*x-y)^2`，对 w 的梯度是 `2*x*(w*x-y)`。梯度下降按 `w -= learning_rate * gradient` 更新参数。学习率太大可能震荡，太小可能收敛慢；梯度是局部变化方向，不保证非凸网络找到全局最优。

LLM 的训练通常围绕 token 预测等目标，真实计算包含大量参数、批次与数值工程。这个标量例子用于理解“损失→梯度→更新”，不能把一个线性回归例子描述为训练出了语言理解能力。

## 训练集表现与泛化

训练损失下降可能只是更好拟合见过的数据。验证集用于选方法和超参数，测试集用于最终持出估计；反复根据测试分数调参会削弱独立性。样本按实体、文档家族和时间切分，避免同一工单改写跨集合泄漏。

| 过程 | 是否更新参数 | 主要风险 |
|---|---|---|
| 提供几个示例给模型 | 通常不更新 | 示例偏差和上下文占用 |
| 梯度训练 | 是 | 过拟合、数据泄漏和数值不稳定 |
| 复用推理缓存 | 通常不更新 | 错误复用与资源占用 |

训练成本和推理成本的组成不同，不能用一次 API 调用价格估算完整训练预算。

## 验收与面试表达

能解释哪些状态变化：推理改变输出和缓存，训练改变参数，业务操作改变外部系统。日志应记录实际模型/训练版本，不能只写“模型学习了用户”。

验证训练至少检查数据切分、训练/验证曲线、基线、随机种子与重复实验、异常值和关键切片。验证推理则检查契约、质量、时延、资源与失败恢复。它们共享模型，却不是同一种工程任务。

## 把机制放到一条完整路径中

```flow
训练与使用
样本前向｜用当前参数得到预测
计算损失｜比较目标并量化误差
反向更新｜梯度与优化器调整参数
独立推理｜固定参数在新输入上评估
```

## 配套代码：训练与推理：参数、损失、梯度与一次更新

下面代码在课内Python运行区执行；浏览器环境与本机CPython的网络、文件和原生扩展能力不同。



```python
w, x, y, rate = 0.0, 2.0, 4.0, 0.1
before=(w*x-y)**2
gradient=2*x*(w*x-y)
w-=rate*gradient
after=(w*x-y)**2
print({'before':round(before,2),'gradient':round(gradient,2)})
print({'weight':round(w,2),'after':round(after,2)})
bad_weight=0-1*gradient
print(round((bad_weight*x-y)**2,2))
```

小学习率使本样本损失下降，大步长会越过目标。这里只更新一个标量参数，不是完整神经网络或 LLM 训练。

## 从示例走向实际使用

修改小模型的学习率与初始值，观察一步更新后损失如何变化，再说明为什么这不能直接代表大模型训练过程。重点是理解参数、预测、目标、损失和梯度之间的关系。

接入 AI 应用时先判断问题是否真的需要训练。缺少最新事实常可通过检索或工具解决，不必把每次数据更新都变成微调任务。
