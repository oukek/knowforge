# 腾讯WXG微信前端面试知识手册（2026最新版）
> 岗位说明：微信前端区别于普通前端，重点考察小程序底层、Skyline、双线程、弱网稳定性、海量用户场景；AI相关为业务线/三面加分项，非一面必考题

## 1. JS 核心基础（一面必考、手写高频）
1. 事件循环：浏览器 vs Node；`setTimeout` / Promise.then / queueMicrotask 执行顺序；`async/await`执行拆解；Node `process.nextTick`优先级
2. this、原型链、闭包、作用域、TDZ；手写 `call/apply/bind/new/instanceof`
3. Promise：手写Promise、`all/race/allSettled/any`；异常穿透、异步并发控制（**带并发限制的调度器是微信高频手撕题**，也会套在wx.request场景）
4. 深浅拷贝、防抖节流、数组扁平化、数组去重、版本号排序
5. ES模块 和 CommonJS 差异、循环依赖；`import()`动态导入

## 2. 浏览器 & 网络原理（多轮高频）
1. URL输入到页面渲染完整流程；DNS、TCP三次握手、TLS握手、HTTP报文、解析HTML/CSS、构建DOM/CSSOM、RenderTree、Layout（回流）、Paint、Composite合成层
2. 缓存：强缓存（Cache-Control/Expires）、协商缓存（Last-Modified/ETag），304；缓存策略选型
3. 跨域：同源策略、CORS预检OPTIONS、JSONP、代理；同源策略存在的意义
4. HTTP/1.1 / HTTP2 / HTTP3 区别；HTTPS完整流程、中间人攻击怎么防御、证书链
5. WebSocket：握手协议、和HTTP关系、同源限制、断线重连、心跳保活（微信IM场景高频）
6. 安全：XSS（存储/反射/DOM，防御：CSP、转义、cookie httponly）、CSRF（token、SameSite）；点击劫持、子资源完整性SRI

## 3. CSS 布局与渲染
- BFC、IFC，清除浮动、margin塌陷；标准盒模型 & IE怪异盒模型
- Flex、Grid；水平垂直居中多种实现方案
- 重排、重绘、合成层；`transform/opacity`为什么不触发回流；will-change
- 层叠上下文、z-index堆叠规则；CSS变量、@container容器查询
- 移动端：viewport、dpr、px/rpx/rem/vw，移动端1px细线方案

## 4. 微信小程序专项（WXG核心重点）
1. **双线程模型**：渲染层（WebView）、逻辑层（JSCore），JSBridge通信；设计原因、缺点、通信序列化开销瓶颈
2. `setData`原理、坑点、优化手段：避免频繁setData、路径局部更新、批量合并更新、大数据setData卡顿原因；`wx.getPerformance`性能打点
3. Skyline渲染引擎：和旧WebView渲染差异、优势、Worklet、原生组件、布局性能优化点
4. 分包加载、独立分包、预分包；分包体积限制、按需加载原理
5. 生命周期：`onLoad/onShow/onReady/onHide/onUnload`；5种路由API区别、页面栈上限
6. 小程序登录流程：`wx.login`获取code、后端换取openid；隐私授权、手机号授权
7. 和H5差异：无window/document、rpx、受限DOM、组件化、原生宿主能力、沙箱隔离；wxml/wxss语法限制
8. 长列表：虚拟列表实现；图片懒加载、WebP、CDN；小程序内存告警、定时器泄漏清理
9. miniprogram-ci、小程序工程化、CI/CD、代码上传

## 5. 前端框架 Vue / React（简历写哪个深挖哪个）
> 微信内部同时存在Vue、React、原生小程序，部分业务自研组件库
### Vue3
- Proxy响应式原理、和Object.defineProperty对比；effect、track/trigger；diff、patch；`nextTick`
- Composition API；Pinia；keep-alive缓存机制

### React

- 合成事件；diff规则；状态管理；Suspense

通用考点：组件通信方案；渲染性能优化、memo、useMemo、useCallback；不可变数据思想

## 8. 性能监控与优化（移动端、弱网重点）
首屏优化链路：
- 网络：CDN、预连接、预加载、资源压缩、懒加载、分页、接口合并、缓存策略
- 渲染：减少DOM节点、虚拟滚动、避免频繁setData、合理使用合成层、减少回流
- 核心指标：FP/FCP/LCP/CLS/TTI；小程序performance指标；埋点、异常捕获、白屏监控
- 弱网专项：请求重试、超时控制、离线缓存、骨架屏、降级方案

## 9. 算法（WXG工程向，偏异步、链表、树）
> 一面一般1~2道手写，重视思路沟通，Hard很少
高频清单：
- 链表：反转链表、环检测、合并两个有序链表
- 树：二叉树遍历、层序遍历、最近公共祖先
- 异步类：并发控制、请求队列、限流（微信招牌题型）
- 数组：三数之和、滑动窗口、合并区间、数组去重
- 字符串：有效括号、字符串匹配
> 真题示例：限制并发的wx.request批量请求，统计平均耗时

## 11. 项目深挖面试官套路（WXG占比最高）
典型追问：
- 项目难点是什么？有哪些备选方案，为什么选当前方案？做了哪些取舍？
- 性能优化前后量化数据（推荐话术：首屏3.2s→1.1s，包体积减少42%）
- 线上出过什么故障，如何排查、修复？复盘得到什么结论？
- 如果重新开发这个项目，你会怎么重构？
- 是否做过小程序、弱网、高并发场景？
> 避坑：不只讲功能，重点讲**取舍、边界、稳定性、降级、监控**

## 12. AI 相关前端面试题（业务线/三面高频，WXG特色）
> 说明：普通业务一二面基本不问；搜一搜、AI插件、AI对话小程序、社招高P、三面/面委大概率问到；**不考Transformer底层算法，只考前端工程、交互、安全、调用链路**

### 12.1 流式输出（SSE / ReadableStream，最高频）
1. SSE 和 WebSocket 的区别？AI对话场景为什么优先SSE？什么时候选择WebSocket？
    - SSE：单向、基于HTTP、自带自动重连、仅文本，适合大模型流式返回；
    - WebSocket：双向通信，适合持续双向交互场景；
    - 坑点：老版SSE不支持自定义请求体、跨域、断流检测、超时、data换行分割、buffer乱码
2. fetch + ReadableStream 实现流式渲染，口述流程
3. 流式渲染：防抖、断流恢复、异常兜底、AbortController取消请求
> 真题：实现AI打字流，支持随时停止生成、网络中断恢复

### 12.2 大模型调用链路、安全与成本（二面高频）
1. 为什么前端不能直接请求大模型API，微信业务都需要后端中转？
    - 密钥泄露、盗刷配额、CORS、计费风险、内容审核（合规）、限流、缓存、数据脱敏
2. Prompt放在前端还是后端，各自利弊
3. 前端输入防护：长度截断、输入过滤、Prompt Injection提示注入防御
4. 降本策略：相同query本地缓存、请求排队、并发控制

### 12.3 AI场景体验与渲染优化
1. 大模型响应慢的体验优化：思考态、骨架流、并行请求、非AI兜底降级
2. 长对话上下文膨胀：摘要压缩、滑动窗口、本地管理上下文，避免全量历史持续上送
3. Markdown/富文本渲染：marked/remark渲染 + DOMPurify防XSS；代码高亮处理

### 12.4 多模态（AI生图、图生图、文件解析）
1. 图片上传：前端本地压缩、分片、WebP、base64 vs Blob选型
2. AI生成大图：预览、懒加载、缓存、失败重试策略
3. 小程序原生AI能力 wx.createAIChatSession：权限、沙箱、限制

### 12.5 Agent / Function Call（偏三面高P）
1. 前端在Agent链路承担什么角色？
    - 工具表单渲染、参数收集、用户确认、流式展示返回结果、中断控制、状态回显
2. function call 前端和后端配合、状态机设计思路

### 12.6 架构选型开放题（总监面）
1. AI时代前端的变化，除调接口渲染之外还能做什么？
2. WebGPU / ONNX Runtime Web 本地端侧推理：限制、适用场景、优缺点
3. RAG检索增强生成，前端负责哪些环节？

### 12.7 辅助开发闲聊题
- 日常如何使用AI辅助编码？如何校验AI产出代码bug？
- AI生成组件如何接入团队ESLint、单测等质量卡点

### 12.8 AI方向手撕真题
1. fetch + ReadableStream 流式解析SSE，逐字渲染回答，AbortController终止请求
2. 对话列表流式追加内容，避免全量重渲染（Vue/React不可变更新）
3. 对话上下文滑动窗口，自动截断超长历史消息

> 不需要准备：Transformer、Self-Attention、模型微调、向量库底层原理

## 13. 总监/面委开放拔高题
1. 前端稳定性如何保障？容灾、降级、灰度发布
2. 大流量场景下前端瓶颈有哪些？
3. 小程序双线程通信瓶颈如何优化？
4. Web、小程序、RN、Flutter跨端技术选型对比
5. 技术选型判断标准；如何推动团队基建落地

## 14. 备考优先级建议
1. 第一优先级：**小程序整套原理 + JS异步手写题 + 网络安全**（WXG区分度最高）
2. 第二优先级：浏览器渲染、框架原理、性能优化
3. 第三优先级：工程化、Node、系统设计
4. 算法：优先刷异步并发、链表、二叉树、滑动窗口，不用死磕困难DP
5. AI内容：简历没有AI相关项目，简单了解SSE/ReadableStream即可；简历有AI对话、生图项目，全套吃透
