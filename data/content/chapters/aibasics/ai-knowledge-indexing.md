## 从具体问题认识知识入库与向量库

知识入库把文件转换成可检索的文档与片段。PDF、网页和表格的可见结构不一定在纯文本提取后保留，标题、列关系和页码都可能丢失。若原始解析已经错误，后续向量检索再精细也只能检索错误材料。

向量库负责存储与搜索表示，它不替你决定文档是否可信、属于谁或是否已过期。这些信息需要作为元数据与生命周期的一部分管理。

## 解析、切分与近似搜索

解析先恢复阅读顺序与结构，表格尤其要保留行列含义。切分在片段长度与语义完整之间取舍：太小容易丢条件，太大可能混入无关内容并增加上下文成本。固定窗口可以作为基线，但标题与段落边界通常需要参与。

每个 chunk 记录文档 ID、版本、位置、来源与访问范围，embedding 记录模型与维度。片段 ID 应能稳定关联更新，不能每次入库随机追加却不删除旧版。元数据过滤必须在检索链路中真实生效，不能只在最终展示时隐藏越权内容。

ANN 是近似近邻搜索，以一定召回损失换取大规模搜索效率；精确搜索计算更完整但成本更高。索引参数、候选数量与过滤方式会影响召回和延迟。应先建立小规模精确基线，再判断近似索引造成多少差异。

## 文档不是天然可检索文本

**入库是把原始资料变成可检索证据的过程。** 例如 PDF 制度先提取文字、标题和页码，再按有意义的段落切块，记录文档版本与访问范围，最后建立关键词或向量索引。

如果表格解析时漏掉表头，检索得到的数字可能失去意义；如果文档更新后旧块没有删除，也可能持续召回过期规则。因此不仅要检查索引建立成功，还要抽样看实际片段、权限和原文定位是否正确。

例如同一制度更新后应标记新旧版本，并防止过期片段继续作为当前生效政策展示。

PDF、表格、图片和网页需要解析；OCR 可能丢字，表格可能失去表头关系，页面导航可能变成噪声。索引前先抽样检查实际文本，保留文档版本与来源定位。原文件读起来正确不代表解析后的片段正确。

Chunk 是用于检索和装配上下文的片段，粒度取决于任务和结构。固定长度易实现，按标题/段落/语义边界更能保留关系，但需要处理超长段、代码和表格。重叠减少边界割裂，也会增加重复、费用和去重难度。

## 元数据不是附属装饰

每块至少有稳定 chunk_id、source_id、source_version、位置与权限范围，还应记录 embedding 版本和构建版本。更新或删除时用这些关系定位派生数据，不靠内容相似猜哪块过期。

| 字段 | 用途 | 缺失后果 |
|---|---|---|
| 来源与位置 | 引用与原文回查 | 只剩无法核验的向量 |
| 租户/ACL | 检索与读取授权 | 相似内容跨用户泄漏 |
| 内容版本 | 更新和缓存失效 | 旧政策残留 |
| 向量版本 | 模型升级 | 不兼容空间混用 |

分块 ID 可以按业务版本规则稳定生成，注意删除再同步不能把旧内容复活。

## ANN 与精确近邻

精确搜索计算所有候选距离；近似近邻 ANN 用索引结构换取更低查询代价。HNSW 是图式近邻方法之一，索引参数影响召回、内存、构建和延迟。向量库还可能支持过滤与混合查询，实际行为要对实现验证。

ANN 的 Recall 与最终答案正确率不是同一个指标。过滤在近邻前后不同可能改变候选覆盖，不能只开一个索引开关就宣布 RAG 完成。

## 如何验收入库质量

准备含标题、否定、跨页表格、代码、扫描件和版本更新的资料，检查原文→文本→块→索引的映射。对删除和撤权做回归，确认向量、缓存、摘要与引用链同步失效。

记录离线解析与 embedding 成本、索引规模、在线召回和生成质量。调优分块时固定语料、问题和最终上下文预算，避免把更多输入 token 带来的收益误认作算法提升。

## 把机制放到一条完整路径中

```flow
知识入库
结构解析｜恢复正文顺序标题与表格关系
片段切分｜保持语义条件和适当长度
关联元数据｜来源版本位置与权限
建立索引｜记录模型并验证近似召回
```

## 配套代码：知识入库与向量库：解析、Chunk、元数据和 ANN

下面代码在课内Python运行区执行；浏览器环境与本机CPython的网络、文件和原生扩展能力不同。



```python
def chunks(items,size,overlap):
    if size<=0 or overlap<0 or overlap>=size:
        raise ValueError('invalid chunk settings')
    result=[]; start=0
    while start<len(items):
        end=min(start+size,len(items))
        result.append({'start':start,'end':end,'items':items[start:end]})
        if end==len(items):break
        start+=size-overlap
    return result

print(chunks(list(range(7)),4,1))
try: chunks([1],2,2)
except ValueError as e:print(str(e))
```

元素只是教学 token，固定窗口不理解段落。end 使用半开区间，最后覆盖到末尾便停止，不生成重复尾块。

## 从示例走向实际使用

抽查解析后的文本与原文件对照，特别是表格、页眉页脚和跨页段落。用已知答案片段测试入库到检索的整条链，确认版本与权限可追踪。

课内固定窗口用于观察边界截断，不是所有文档的最佳切分方法。根据失败样本调整分块，而不是盲目把 chunk 越切越小。
