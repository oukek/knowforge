## 从具体问题认识AI 指标入门

评价 AI 先确定评价对象：分类结果、检索候选、生成答案还是完整任务。Accuracy、Precision、Recall、F1 与困惑度回答不同问题，不能因为都是数字就放在同一张表中直接比较。

垃圾邮件识别中，误拦正常邮件与漏掉垃圾邮件的代价不同。即使总体准确率很高，少数关键错误仍可能让产品不可用。

## 混淆矩阵与业务损失

对二分类，真正例是正确识别目标，假正例是把非目标误判为目标，假负例是漏掉目标。Precision 看被判为目标的结果中有多少正确，Recall 看所有真实目标中找回多少。F1 用调和平均平衡两者，但并不表达所有业务代价。

类别极不平衡时，全部预测为多数类也可能得到很高 Accuracy。应按类别与场景切片，检查样本数量、标注一致性和数据泄漏。阈值改变会在误报与漏报之间移动，需要根据实际损失选择，而不是只追求最高单一指标。

困惑度衡量模型对给定序列预测的某种不确定程度，依赖 tokenizer、数据与计算方式，不等于应用事实正确率。生成任务通常还要评估证据、格式、完整性与安全，Agent 则需要任务成功、工具合法性与成本等指标。

## 指标先明确评价对象

**评价指标先要明确分子和分母。** 例如 100 封邮件中有 10 封垃圾邮件，系统标出 8 封，其中 6 封确实是垃圾邮件：Precision 为 6/8，表示标出的邮件中有多少正确；Recall 为 6/10，表示真实垃圾邮件中找回了多少。

Accuracy 看全部判断中正确的比例，类别严重不平衡时可能掩盖对少数类的漏判。F1 综合 Precision 和 Recall，但不能取代对误报与漏报业务代价的判断；生成与 Agent 任务还需要检查证据、动作和最终结果。

分类任务评价预测标签，检索任务评价候选证据，生成任务评价输出支持与约束，Agent 还要评价轨迹和副作用。相同的“准确率”一词可能用了不同样本和分母，必须先定义事件与标注。

二分类中 TP 是正例判正、FP 是负例误判正、FN 是正例漏判、TN 是负例判负。Accuracy=(TP+TN)/全部；Precision=TP/(TP+FP)；Recall=TP/(TP+FN)；F1 是精确率与召回率的调和平均。高精确率不保证召回高，类别不平衡时准确率容易误导。

## 用业务损失理解取舍

风险识别中漏报和误报代价不同，阈值会影响两者；多分类需要宏/微平均和类别切片。无正例或无预测正例时，分母为零必须制定约定，不能悄悄输出漂亮的满分。

| 对象 | 常见指标 | 不宜替代 |
|---|---|---|
| 分类 | Accuracy、P/R/F1 | 生成事实支持 |
| 检索 | Recall@k、MRR | 最终业务完成 |
| 语言概率 | 交叉熵、PPL | 工具权限和答案真实性 |
| 业务任务 | 成功、违规、成本 | 单一模型分数 |

PPL 常由平均负对数似然取指数得到，反映特定数据和分词条件下的预测难度；不同 tokenizer 或语料上的数不能不加条件直接比较。

## 数据集比公式更决定结论

标注集要包含真实高频、困难、无答案、冲突和故障样本；训练、调提示与最终测试分开。合成数据可以补覆盖，但应审计重复、错误答案和模板偏差，不能只让同一个模型出题再给自己满分。

同时报告切片、样本量和不确定性，别用总体平均掩盖少数语言或高风险动作退化。开放答案采用人工或模型裁判时，裁判也需校验与版本记录。

## 从指标接到发布

对固定任务做配对比较，检查质量、关键安全违规、延迟及每成功任务成本。失败调用和人工审核成本不能从分母里消失。具体阈值由业务风险决定，不复制别人的 90%。

面试时先说指标定义与数据来源，再说分数和改进。不确定的生产数字不要编造，可展示你如何构建标注、计算并验证脚本。

## 把机制放到一条完整路径中

```flow
评估设计
明确对象｜分类检索回答或完整任务
建立标注｜定义正确与错误及业务代价
选择指标｜按切片计算并检查分布
支持决策｜用可比实验指导上线与回退
```

## 配套代码：AI 指标入门：Accuracy、Precision、Recall、F1 与 PPL

下面代码在课内Python运行区执行；浏览器环境与本机CPython的网络、文件和原生扩展能力不同。



```python
def metrics(tp,fp,fn,tn):
    def divide(a,b):return a/b if b else None
    p=divide(tp,tp+fp);r=divide(tp,tp+fn)
    f1=divide(2*tp,2*tp+fp+fn)
    return {'accuracy':divide(tp+tn,tp+fp+fn+tn),'precision':p,'recall':r,'f1':f1}

print({k:round(v,4) if v is not None else None for k,v in metrics(2,1,2,5).items()})
print(metrics(0,0,1,9)['precision'])
```

零分母显式返回 None。这里评价给定的分类计数，不把这些指标自动当作 RAG 忠实度或 Agent 业务成功率。
