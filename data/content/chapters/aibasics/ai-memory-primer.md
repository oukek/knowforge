## 从具体问题认识Agent 记忆入门

Agent 记忆不是一种单独数据库能力，而是关于哪些信息需要跨步骤或跨会话保留的一组设计。短期状态支持当前任务，长期记忆保存以后可能有用的偏好或事实，知识库保存可检索资料；它们的来源、权限和更新规则不同。

用户今天说“这次报告写短一点”，未必表示以后所有报告都要短。把一次情境要求永久存成偏好，就是记忆提取错误。

## 记忆的写入、读取与遗忘

写入前判断信息是否稳定、是否得到明确支持、是否值得跨会话保留，并记录来源、时间与作用域。模型推测不能自动升级为用户事实。敏感信息需要更严格的保存与访问规则，用户应能查看、纠正或删除相关记忆。

读取时按当前用户、任务与有效期筛选，再做相关性检索。语义相似的旧偏好可能已经失效，最新明确指令应优先于旧记录。冲突信息可以保留版本与待确认状态，不应简单把所有文本拼进上下文让模型自己猜。

长期记忆可以采用结构化字段、事件记录与检索索引组合，不等于把所有对话向量化。删除需要同步到派生索引与缓存，摘要也要更新，否则主记录删除后仍可能被旧摘要重新引入。

## “记忆”包含几个不同问题

短期状态帮助同一任务继续，例如已查过哪些资料、还缺什么字段；长期记忆帮助跨任务复用经确认的偏好或知识；业务事实由业务数据库负责，知识库保存资料。把它们都塞入向量库，会失去各自一致性和删除规则。

检查点记录运行状态，可能支持中断恢复，但不是业务副作用的去重证明。聊天摘要便于上下文装配，却不能替代已退款凭据。某些框架提供 checkpointer 与 store，应用仍需决定具体保存内容和作用域。

## 哪些值得长期记住

稳定且明确确认的偏好、经核验且可更新的事实可考虑长期保存；一次性指令、模型推测、秘密和过期订单状态不应自动升级。记录 tenant、subject、key、value、source、confirmed、expires_at、version 和撤回信息。

| 信息 | 默认策略 | 原因 |
|---|---|---|
| “今天用英文” | 当前任务范围 | 不代表永久偏好 |
| 常用语言经确认 | 可作长期偏好 | 仍需可修改删除 |
| 支付已完成 | 查业务系统 | 高风险权威事实 |
| 模型猜的职业 | 不作确认事实 | 来源不足 |

重复检索到同一句推测不会使它变成真实事实，来源可信度由宿主策略决定。

## 读取、冲突和遗忘

先按租户、主体、用途和权限过滤，再检索相关记忆。值冲突时按版本和来源规则处理，无法判定应保留冲突并询问。过期信息不再影响决策，用户纠正应覆盖适用作用域，而不是随便删除最新记录。

删除需传播到索引、缓存与摘要，并用删除版本防止迟到同步复活。备份与日志有不同保留周期，应说明可撤回边界，不承诺“删一行数据库就从所有地方忘掉”。

## 验收与下一步

测试新增、修改、冲突、过期、撤回、跨会话和跨租户；评估记忆带来的任务收益以及错误记忆造成的伤害。命中率高不是质量保证。

学习后应能为同一个信息选择合理存储：消息历史、任务状态、长期偏好、知识库或业务事实库，并解释谁有权更新。记忆设计从作用域与生命周期开始，而非从选向量数据库开始。

## 把机制放到一条完整路径中

```flow
记忆生命周期
提取候选｜识别稳定事实与情境要求
验证保存｜记录来源范围时间与权限
按需读取｜筛选有效且相关的记忆
纠正遗忘｜处理冲突过期与彻底删除
```

## 配套代码：Agent 记忆入门：短期、长期、知识与状态

下面代码在课内Python运行区执行；浏览器环境与本机CPython的网络、文件和原生扩展能力不同。



```python
def active(records,subject,now):
    return [r['value'] for r in records if r['subject']==subject and r['confirmed'] and now<r['expires_at']]

rows=[dict(subject='u1',value='zh',confirmed=True,expires_at=10),
      dict(subject='u1',value='en',confirmed=False,expires_at=10),
      dict(subject='u2',value='ja',confirmed=True,expires_at=10)]
print(active(rows,'u1',9))
print(active(rows,'u1',10))
```

这是有效性过滤，生产还需租户、访问控制、撤回与版本。多个有效值冲突仍需独立规则处理。

## 从示例走向实际使用

为偏好建立作用域，例如本次任务、某项目或全局，并通过具体例子确认。测试用户修改偏好、两个来源冲突、跨账号检索与删除后再次询问。

课内只选择当前有效偏好，真实系统还要处理来源可信度与冲突解决。记住更多不一定更好，错误记忆可能比没有记忆更难发现。
