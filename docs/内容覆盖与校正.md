## 证据与校正

1. **面试流程/频率**：没有提供原始招聘通知与真实面经来源，未把“必考、高频、三面大概率”等判断当事实。所有题为编辑构造练习。
2. **双线程**：传统 WebView 和 Skyline 分开说明，平台 JS 引擎不统一叫 JSCore。
3. **SSE**：区分事件流格式、原生 EventSource API 与 fetch 流。EventSource 支持正确配置的跨域；fetch POST 可以接收 SSE，但重连需自行管理。
4. **指标**：补当前核心 LCP/INP/CLS，区分 Web 指标与小程序指标。
5. **业绩数字**：原文“3.2s→1.1s、42%”没有证据，作为不应照抄的案例处理。
6. **wx.createAIChatSession**：本次候选官方路径为 404，公开检索未获取足够依据；这不证明所有灰度/内部环境都不存在该能力，但足以说明不能作为通用 API 教学。
7. **提示注入**：前端过滤只是辅助，权限与副作用工具必须在服务端受控。
8. **合成动画**：补充纹理、显存和图层成本，不声称 transform/opacity 永远免费。

- 微信官方 Skyline 架构页、官方 Skyline 资料仓库：渲染架构与迁移边界。
