## 从具体问题认识有效括号、栈与流式解析

栈是一种后进先出的数据结构，最后放入的元素最先取出。括号匹配适合用栈，因为最近出现但尚未闭合的左括号，必须由下一个对应右括号先关闭，这与嵌套结构的顺序一致。

([]) 合法，因为方括号先闭合，再闭合圆括号；([)] 不合法，即使每种括号数量相同，关闭顺序也破坏了嵌套。只统计左右括号数量无法判断多类型嵌套。

## 栈顶表示当前必须完成的结构

遇到左括号就压栈，遇到右括号则检查栈顶是否为对应左括号。栈为空或类型不匹配时立即失败；扫描结束后栈必须为空，否则还有未闭合结构。这个不变量是“栈中按出现顺序保存尚未闭合的左括号”。

例如读到 ([ 后栈为圆括号、方括号，下一字符若是 )，需要关闭圆括号，但当前最内层仍是方括号，必须拒绝。处理每个字符只做固定数量操作，时间 O(n)，最坏额外空间 O(n)，对应全部都是左括号的输入。

流式解析可以在数据块之间保留这个栈，不要求一次拿到完整字符串。但只有收到结束标记后，才能把剩余非空栈判为最终缺失闭合；中途非空是正常状态。真实语言解析还要处理字符串、转义和注释，不能把文本中所有括号都直接当语法括号。

## 把机制放到一条完整路径中

```flow
括号匹配
读取字符｜识别左括号右括号或非法字符
压入结构｜左括号成为当前最内层
检查关闭｜右括号必须匹配栈顶
检查结束｜输入耗尽后不得有未闭合项
```

## 配套代码：把机制变成可运行函数

下面代码在课内JavaScript运行区执行；需要DOM、Node或平台SDK的真实集成，应按正文的运行边界另行验证。

顺序和类型同时匹配，仅统计括号数量不够。

```javascript
function validBrackets(text) {
  const pairs={')':'(',']':'[','}':'{'},stack=[];
  for(const c of text){if('([{'.includes(c))stack.push(c);else if(pairs[c]){if(stack.pop()!==pairs[c])return false}else return false}
  return stack.length===0;
}


console.log(validBrackets('([]{})'));
console.log(validBrackets('([)]'));
console.log(validBrackets('(a)'));
```

第二个输入数量相同但嵌套类型错；第三个因本题仅允许括号而失败。解析真实 JavaScript 还要识别字符串、注释等，不能只用这个栈。

## 从示例走向实际使用

先确认题目是否只允许括号字符。课内实现遇到其他字符会返回 false，因此 (a) 不属于允许输入；如果题目要求忽略普通字符，应明确修改规则。

测试空串、单个右括号、未闭合左括号、多层嵌套与交错类型。用逐字符表记录栈状态，能直接指出错误首次发生的位置。
