## 从具体问题认识多模态与 AIGC

多模态系统处理文本、图像、音频或视频等不同信息类型。OCR 把图像中的文字转成文本，ASR 把语音转成文字，TTS 把文字转成语音，图像或音频生成则产生新的媒体内容。它们不能因为都叫 AI 就采用相同评估方式。

例如会议助手需要识别语音、区分时间与说话人、整理要点，再把结论关联到原音频片段。中间任何一步出错，都可能影响最终纪要。

## 媒体预处理与证据对齐

图像输入可能被缩放、裁剪或分块，细小文字与表格关系可能因此丢失。音频需要考虑采样、噪声、分段与重叠说话，视频还同时包含时间顺序和多帧关系。预处理不是无关步骤，它决定模型实际看见或听见什么。

提取结果应保留来源位置，例如图片区域、页码、音频时间段与说话人标签。生成摘要时可以回到这些位置验证，避免把多个人的观点合并成同一人承诺。OCR 识别出字符，也不代表表格行列关系已正确恢复。

生成媒体的质量要按任务定义：是否符合描述、主体是否一致、文字是否准确、是否满足尺寸与时长。调用成功只说明服务返回产物，不说明业务验收通过。费用与延迟还可能按分辨率、时长或其他模型规则计量，不能统一按文本 token 推算。

## 模态描述输入输出的信息类型

文本、图像、音频和视频是不同模态。OCR 把图中文字转成文本，ASR 将语音转文字，TTS 将文字转语音；VLM 等视觉语言模型结合图像与文本完成理解和生成文本。图像生成与视频生成又是不同输出任务，不能因为模型“多模态”就假定支持任意双向转换。

AIGC 常用于描述 AI 生成内容，涵盖文案、图像、音视频等。具体模型支持哪些输入、输出和格式，需看模型卡与接口，不能仅用产品名推定能力。

## 从媒体到可用事实

图片可能经过缩放、切块和编码，音频涉及采样、语音识别与时间戳，视频涉及帧和音轨的时序对齐。预处理会丢失细节：小字、快速动作、字幕和说话人归属都可能错。将视频只抽一帧无法证明完整事件过程。

| 任务 | 关键风险 | 验收重点 |
|---|---|---|
| OCR 表格 | 表头与单元格关系丢失 | 字段、单位与原图位置 |
| ASR | 同音词与专有名词 | 时间戳、词错率与业务字段 |
| 图文理解 | 图像与文字冲突 | 来源分开、不得盲信字幕 |
| 长视频总结 | 分段丢上下文 | 时序、跨段事件与引用 |

保留原媒体位置和处理版本，便于把最终主张定位到具体片段。

## 生成模型的一点直觉

扩散类生成常从噪声逐步去噪形成样本，文本等条件影响过程；并非所有图像或视频生成都使用完全相同架构。生成的图片看起来真实不等于记录了真实事件，理解任务和内容创作要采用不同事实标准。

多模态输入同样存在不可信指令，例如图片中的恶意文字。解析出的内容仍是数据，工具和业务权限由宿主控制。敏感媒体上传还要考虑用户授权、保留与访问范围。

## 可靠应用怎样验收

先验证单模态解析，再验证融合与最终任务。对嘈杂音频、小字、长视频、跨段指代、说话人混淆和图文不一致分别建集，记录质量、延迟、token/媒体费用与来源覆盖。

面试需要把“上传→存储→异步处理→分段→模型→汇总→引用”的服务链讲清，并解释失败重试、权限和大文件资源上界。会调用一个多模态 API 不等于完整媒体系统已经可靠。

## 把机制放到一条完整路径中

```flow
多模态应用
准备媒体｜检查格式质量与授权范围
预处理编码｜保留空间时间与结构信息
模型处理｜识别理解或生成目标内容
证据验收｜关联来源并按任务标准验证
```

## 配套代码：多模态与 AIGC：图文、OCR、ASR、TTS 与生成

下面复用本课的确定性机制实验，只表达所讨论的局部关系，不等于真实宿主、数据库或模型服务。



```javascript
function overlapSegments(segments, start, end) {
  if (!(start < end)) throw Error("invalid window");
  return segments
    .filter((s) => s.start < end && s.end > start)
    .sort((a, b) => a.start - b.start)
    .map((s) => s.id);
}
const segments = [
  { id: "s3", start: 20, end: 30 },
  { id: "s1", start: 0, end: 10 },
  { id: "s2", start: 10, end: 20 },
];
console.log(overlapSegments(segments, 10, 20));
console.log(overlapSegments(segments, 9, 21));
```

半开时间区间帮助精确定位媒体证据；示例没有运行真实 OCR、ASR、图文模型或生成模型。

## 从示例走向实际使用

从一个明确媒体任务建立原始输入、预处理、模型输出与人工核对链。测试低分辨率、噪声、遮挡、空白和跨片段关系，检查系统能否表达不确定。

课内时间片段模型展示证据对齐，不是真实语音识别器。应用应保留必要来源，同时管理媒体权限与保存期限。
