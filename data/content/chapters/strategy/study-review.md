## 从具体问题认识检索练习、间隔复习与错题归因

检索练习是暂时不看资料，尝试从记忆中解释或解决问题，再用反馈纠正。它与反复阅读不同：阅读容易产生“看着熟悉”的感觉，检索则暴露哪些关系还无法独立组织。间隔复习把再次练习分散到不同时间，帮助检查知识是否真正保留。

复习不应只是重新做同一道题。若已经记住答案字符串，正确率可能上升，但换个变量名或场景仍会失败，需要加入机制相同、表面不同的迁移题。

## 错题归因决定下一步动作

把错误分成题意理解、概念定义、机制推导、实现细节和验证遗漏等类别。题意没读懂时应重述输入输出；机制不清时回到最小例子；实现错误时跟踪状态；边界遗漏时主动构造反例。对所有错误都采用“再读一遍答案”，往往没有针对性。

复习记录保留当时的回答与修改理由，而不只保存对错。一次猜对不代表掌握，一次笔误也不代表整个概念不懂。可以结合信心程度：高信心错误尤其值得检查，因为它可能来自稳定但错误的心智模型。

间隔长度应随掌握情况调整，没有适合所有人和所有课程的唯一日程。近期反复出错的知识更早复习，能稳定解释并迁移的知识拉长间隔。复习任务也应轮换口述、代码与场景判断，避免只训练一种输出形式。

## 把机制放到一条完整路径中

```flow
有效复习循环
独立检索｜不看资料先解释或实现
对照反馈｜定位具体错误与遗漏
针对修正｜补概念推导代码或边界
间隔迁移｜稍后用不同表面的题验证
```

## 配套代码：简化间隔规则的确定性计算

下面代码在课内JavaScript运行区执行；需要DOM、Node或平台SDK的真实集成，应按正文的运行边界另行验证。

演示当前项目的学习间隔，而非完整 FSRS 或学习效果保证。

```javascript
function interval(previous,rating) {
  if(rating===0)return 10/1440;
  if(rating===1)return 1;
  return rating===2?Math.max(2,Math.round(previous*1.8)):Math.max(4,Math.round(previous*2.5));
}
console.log(interval(0,2));
console.log(interval(2,3));
console.log(interval(5,1));
```

首次独立回答至少 2 天，再很稳可到 5 天，困难则缩回 1 天。记忆强度并非由这一公式精确描述，开放题自评也需要主动回忆验证。

## 从示例走向实际使用

每道错题写一句“我原来误以为……”和一句“现在依据是……”，再做一个变体确认理解。若只是复制标准答案，记录很完整也未必产生学习。

复习时先尝试再展开答案，完成后比较关键机制而不是逐字匹配。主观题的自动评阅应帮助发现遗漏，不能替代自己核对事实与边界。
