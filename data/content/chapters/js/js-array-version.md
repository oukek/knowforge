## 从具体问题认识扁平化、去重、版本比较与复杂度

数组工具题首先是一份数据契约，不只是调用哪个API。扁平化要说明展开几层、是否保留空槽，去重要说明怎样判断相同，版本比较要说明字符串遵守哪套版本语法。没有这些条件，一个很短的函数可能通过示例却不满足实际需求。

数组有顺序且允许重复，Set使用规定的值相等语义，Map按键关联值；对象内容看起来一样不等于对象引用相同。版本号则通常由多个整数段组成，不能当浮点数处理，1.10与1.2的顺序不是小数大小。

## 遍历、身份与分段比较

扁平化可以递归访问嵌套数组，也可以用显式栈保存待处理项。每个元素被访问的次数决定时间成本，反复拼接大数组还可能造成额外复制；极深嵌套可能超过调用栈。展开深度应作为参数契约，检测Array使用Array.isArray，而不是假定所有对象都可递归展开。

去重若按对象ID，应先提取稳定键再记录是否出现，并明确保留首次还是末次、是否维持原顺序。直接JSON.stringify对象当键会受到字段顺序和类型表达的影响，不是通用结构相等。Set中的NaN可以去重，正负零的规则也与Object.is不同，语言API的相等语义要与业务匹配。

版本比较依次解析对应数字段，找到第一个不同段决定顺序，缺失段是否补零由版本约定决定。若输入包含预发布标签或构建元数据，需要完整SemVer规则，不能继续沿用“按点分割再Number”的简化算法。来自外部的版本段还要限制长度，防止数值精度和超大输入问题。

## 把机制放到一条完整路径中

```flow
数组工具的设计顺序
定义输入与相等规则｜深度、顺序、重复和版本语法
选择遍历结构｜递归、栈、Set或Map
处理边界与身份｜不把引用相等误当结构相等
验证规模成本｜访问次数和中间复制一起计算
```

Set 的相等规则、flat 的深度与 sort 比较器解决不同问题。

```javascript
console.log([1, [2, [3]]].flat(1));
console.log([...new Set([1, 1, NaN, NaN])].map(String));
console.log([2, 10, 1].sort());
console.log([2, 10, 1].sort((a, b) => a - b));
```

flat(1) 只展开一层，Set 能去重 NaN，默认 sort 按字符串比较；数值排序需要比较器。这里不把点分版本当浮点数处理。
