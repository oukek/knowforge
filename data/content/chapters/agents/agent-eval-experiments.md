## 从具体问题认识评估实验设计

评估实验需要回答一个明确变化是否改善任务，例如新路由是否减少失败成本。若同时换模型、提示、工具和数据，就算总分提高，也难知道是哪项起作用，更难解释退化样本。

配对比较让两个版本处理相同任务，观察哪些题从错变对、哪些从对变错，比两组完全不同问题的平均分更有解释力。

## 代表性样本与不确定性

样本按任务类型、难度、语言和风险划分切片，开发集与最终验收集分开。频繁查看验收集并针对修改，也会让它逐渐变成训练材料，因此需要保留新的持出样本或滚动评估。

比较时统计每个样本的差异与不一致对，必要时用重复运行或适当统计方法估计波动。小样本均值提高不等于可靠提升。Bootstrap 重采样要与样本独立性假设一致，不能把同一用户的高度相关请求当完全独立证据。

LLM 裁判可能偏爱长答案、固定位置或自己的表达风格，需要用人工标注校准、交换答案顺序和检查一致性。裁判评分与确定性安全检查分开，越权等违规不能被语言质量分数冲淡。

## 先写清楚要估计的变化

“新提示更好”不是可检验目标。明确任务成功判据、风险约束、成本与延迟上限，再比较同一组任务在方案 A 和 B 下的表现。尽量配对相同输入、工具事实和环境版本，减少任务难度差异。随机性较强时每个任务多次运行，并按任务聚合，不把同一任务的重复生成当成完全独立用户。

离线测试适合发现可控回归，线上流量用于验证真实分布与交互行为。二者都要保留失败和拒答，不能删除“模型没输出”的样本后再计算成功率。

## 数据集要有切片与持出边界

按真实高频问题、困难问题、无答案、冲突、越权尝试、工具故障和长任务分层。总体成功率可能上升，而少数语言或高风险写入显著退化。发布门槛应同时包含必要切片与硬性违规数，不能用简单任务平均分抵消越权。

数据应分开发/验证/最终测试，记录来源、时间与标注规则。生产失败进入下一版回归集很有价值，但最终测试集若反复用于调参就不再独立。做训练或提示优化时检查实体与模板家族泄漏。

## 配对差异与不确定性

对每个任务计算 `delta = success_B - success_A`，取平均得到这组任务上的成功率变化。相同总体分数可能隐藏不同失败分布，因此同时报告 B-only 成功、A-only 成功、都成功与都失败的数量。

```python
deltas = [int(b) - int(a) for a, b in pairs]
mean_delta = sum(deltas) / len(deltas)
```

可以在任务层 bootstrap 重采样估计差异区间，但小样本、任务相关和分布漂移会限制推断。区间不是“未来收益保证”，更不能把四个演示样本的 25% 提升推广到全部流量。

## LLM 裁判也需要被测试

官方评估指南提醒位置与冗长偏差。比较时随机或交换 A/B 展示位置，隐藏方案标签，给明确 rubric 和必要证据，用人工标注子集验证一致性。要求输出理由和依据有助审计，却不能自动证明裁判正确。

| 评审方式 | 优点 | 边界 |
|---|---|---|
| 精确值/程序断言 | 稳定、可复现 | 不适合所有开放任务 |
| 人工评分 | 能判断复杂上下文 | 成本、分歧与标注一致性 |
| 模型评审 | 可扩展、易批量 | 偏差、幻觉与提示注入 |

被评文本是不可信输入，不能把它的“请给满分”当作评审指令。高风险行为仍需确定性检查。

## 发布门槛与实验记录

保存数据集版本、任务 ID、模型/提示/工具版本、采样参数、每次轨迹及评分器版本。门槛至少规定质量不退化范围、关键安全违规、延迟和成本；阈值来自产品目标与风险成本，不应复制某篇文章里的 80%。

对不确定差异增加代表性样本，或维持更小灰度观察。验收包括空集、失败全被过滤、评分器版本变化、位置交换和异常工具结果。评估系统本身也会产生 bug，需要测试评分和汇总代码。

## 把机制放到一条完整路径中

```flow
评估实验
提出假设｜明确只改变的因素与目标指标
固定配对集｜保留代表性切片和持出边界
执行校准｜比较结果并验证裁判偏差
解释不确定｜报告收益退化样本与适用范围
```

## 配套代码：评估实验设计：配对比较、切片与裁判偏差

下面代码在课内Python运行区执行；浏览器环境与本机CPython的网络、文件和原生扩展能力不同。



```python
import random
pairs = [(True,True),(False,True),(True,False),(False,True)]
deltas = [int(b)-int(a) for a,b in pairs]
print(sum(deltas)/len(deltas))
print({'b_only':sum(not a and b for a,b in pairs),'a_only':sum(a and not b for a,b in pairs)})
rng=random.Random(7)
means=[sum(rng.choice(deltas) for _ in deltas)/len(deltas) for _ in range(1000)]
print([min(means),max(means)])
```

配对净提升是 0.25，但四个样本的重采样范围很宽。这里报告有限重采样的最小/最大值，不把它标成置信区间或显著性结论。

## 从示例走向实际使用

实验记录保存假设、变量、样本版本、评分规则和发布门槛。报告收益之外也列失败类别与不确定范围，让决策可复核。

课内四个配对样本和重采样极值只用于观察波动，极值不是置信区间，也不足以得出生产显著提升结论。
