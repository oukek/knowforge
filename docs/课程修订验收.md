## 本轮校正的示例边界

1. 爬虫重试先计算本地退避，再尊重服务端 `Retry-After` 的最小等待；服务端要求 120 秒时，不再被本地 30 秒退避上限截短。
2. 余弦相似度示例拒绝维度不一致及非有限数值，避免 `zip` 静默截断。补全题增加维度不匹配用例；极端浮点数稳定化仍作为明确边界说明。
3. MySQL 二级索引模型改为不同二级键，避免相同键下无序主键的例子误导真实索引顺序；人为页映射与真实 InnoDB 物理布局明确区分。
4. MCP 入门与进阶都说明协议版本前提，区分传统初始化与现代按请求协商，避免将某一版本机制当成通用规则。
5. Transformer 和量化课程合并重复定义，增加残差/前馈职责与浮点格式比较；算法课程清理正文与实验解说中的重复段落。
