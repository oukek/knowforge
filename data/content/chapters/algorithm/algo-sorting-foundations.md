## 从具体问题认识排序入门

排序按照指定比较关系重新排列元素。数字升序、按成绩降序再按姓名排序，是不同的规则。稳定排序还要求比较相等的元素保持原来的相对顺序，这在多字段处理与已有时间顺序时很有用。

例如两位学生同为 90 分，稳定排序可以保留原来的报名顺序。稳定性不是“每次运行结果一样”，而是对相等元素顺序的具体保证。

## 从插入排序理解已排序部分

插入排序维护一个已经有序的前缀。拿出下一个元素，把前缀中比它大的元素逐个向右移动，找到合适位置后插入。若只移动严格更大的元素，相等元素不会越过彼此，因此保持稳定；若条件改成大于等于，稳定性就可能被破坏。

比较器必须表达一致顺序。JavaScript 默认数组排序按字符串形式比较，所以 [10,2,1] 不会得到数值升序；数值通常使用 (a,b)=>a-b，但含 NaN、超出安全整数或特殊对象时还需明确策略。比较器若对同一对元素给出矛盾结果，算法无法保证合理排序。

合并两个有序数组时，每次比较当前两个头部，取较小者加入结果。每个元素只移动一次，所以是线性时间。归并排序通过递归排序两半再合并，把这个局部性质扩展到整个数组，通常时间 O(n log n)，但需要相应辅助空间。计数排序则依赖值域较小，不能只看元素个数。

## 排序到底保证什么

排序根据键重新排列，通常需要保持元素多重集不变，重复项不能丢失；去重是另一个操作。先确定升序、降序与同键规则。报名记录按成绩排，成绩相同保留报名顺序，这叫稳定性，不是程序每次运行结果一样。可把输入位置作为次关键字明确规则；名称、年龄之类业务字段不能擅自加入比较器。

## 用插入排序理解有序前缀

输入 [4,1,3,2]：开始只有 [4] 有序；拿出 1，向右挪 4，得到 [1,4,3,2]；拿出 3，挪 4，得到 [1,3,4,2]；拿出 2，挪 4、3，最后成为 [1,2,3,4]。每次循环前 [0,i) 都已排好，这是不变量。插入时仅移动严格大于当前键的元素，可保留等值记录的原序。

它的最坏移动次数为 1+2+…+(n-1)，是 O(n²)，但近乎有序输入可能较快。冒泡通过相邻交换推进，选择排序每轮找最小后交换，三者不能只因都有两层循环就认作同一算法。选择排序直接交换可能破坏稳定性。

## JavaScript 的比较器与数值陷阱

[10,2,1].sort() 的结果为 [1,10,2]，因为默认按字符串顺序比较。数值可用 (a,b)=>a-b；降序反过来。比较器应满足一致性，不能写返回 boolean 的 a>b，也不能依赖每次变化的随机数。对很长数字字符串的拼接问题应比较字符串拼接结果，不能转成 Number 后比较失去精度的整数。

## 合并两个有序数组为什么线性

A=[1,4,7]，B=[2,4,5]：两个头部中较小的是全体未输出元素的最小值，取走并推进对应指针。两边相等时先取 A 可保留来源顺序；一边耗尽后将另一边余项接上。每个元素只被推进一次，总 O(n+m)，重复的 4 都应保留。若重新拼接再完整排序，会浪费已经有序的信息。

## 归并排序和计数排序各依赖什么

归并把单元素段视为有序段，不断合并为更长的有序段，总共约 log n 层，每层线性工作，额外缓冲为 O(n)。计数排序依赖值域 V 较小，时间为 O(n+V)，并不适合分配一个覆盖 10^9 值域的数组。比较排序的下界前提与非比较排序不同，不能只说某个名字永远最快。

## 练习和验收

先完成数值排序、稳定报名记录、合并已排序名单、三色分类，再做相对排序与拼接最大数。每次都检查长度、频次、顺序和同键规则。用全相同、逆序、奇数长度、空的一边与超过 32 位的值回归。原地排序会改变输入，若调用者还要原数组，就明确复制；稳定不等于原地，原地也不等于低时间复杂度。

## 把机制放到一条完整路径中

```flow
建立排序规则
定义比较｜确定键方向与相等规则
维护局部有序｜插入或合并已知有序部分
扩展范围｜逐步覆盖全部输入
验证契约｜检查顺序稳定性与输入修改
```

## 配套代码：排序入门：比较器、稳定性与有序合并 · 手推后运行

先预测输出，再修改一处输入，检查你的状态与不变量解释是否成立。

```javascript
function insertion(rows){const a=rows.map(row=>({...row}));for(let i=1;i<a.length;i++){const current=a[i];let j=i-1;while(j>=0&&a[j].score>current.score){a[j+1]=a[j];j--;}a[j+1]=current;}return a;}
const rows=[{score:2,name:'A'},{score:1,name:'B'},{score:2,name:'C'}];
console.log(insertion(rows).map(row=>row.name));
console.log([10,2,1].sort());
console.log([10,2,1].sort((a,b)=>a-b));
```

插入排序的每轮先保存待插入的值，再把更大的前缀元素向右移动，最后填入空位。保存当前值避免移动时覆盖它；数组较小时可以逐轮打印，确认前缀有序这个不变量始终成立。

它的最坏移动次数为 1+2+…+(n-1)，是 O(n²)，但近乎有序输入可能较快。冒泡通过相邻交换推进，选择排序每轮找最小后交换，三者不能只因都有两层循环就认作同一算法。选择排序直接交换可能破坏稳定性。

## 从示例走向实际使用

先明确排序键、升降序、相等时规则和是否允许修改输入，再选实现。对带身份的对象测试稳定性，仅用重复数字无法观察相等元素是否交换。

手推 [3,1,2] 的插入过程，记录每一轮有序前缀。之后读归并与快速排序时，继续寻找它们各自维护的局部事实。
