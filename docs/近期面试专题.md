收录于 2026-10-24。22 条原题来自用户对朋友近期面试的转述，未提供公司、准确面试日期与原始记录；未独立核实，不能据此宣称某公司高频或命中率。参考答案为本项目整理；60 条延伸题明确标为原创推演。

## 怎样理解面试官的考查路线

这些问题有一条共同线索：要求候选人把“能做演示”推进到“能解释故障、约束、成本和维护”。以下是基于这份问题样本的推断，不是行业出题频率统计。

1. **从术语进入执行路径。** 聚簇/二级索引会追问取了什么页，RAG 会追问证据在哪一步丢失，Agent 会追问谁实际执行了动作。准备时要画时间线，区分逻辑机制和物理观测。
2. **从理想路径进入异常。** 供应商限流、流中断、工具成功但响应丢失、旧索引任务晚完成、记忆冲突，是比“用了什么框架”更深入的检验。每个方案都要能说明失败状态、是否可重试、能否重复扣款和如何恢复。
3. **从功能进入授权与资源。** SaaS 与 Agent 都需要可信身份、租户边界、最小工具、配额和审计。模型判断、提示、随机 ID 与独立数据库都不能单独替代授权。
4. **从效果声明进入可复现实验。** 回答“召回提升”“Agent 更聪明”时要说样本、分母、版本、预算和人工校准；把召回、排序、生成、业务结果拆开，避免一个总分掩盖安全或长尾退化。
5. **从工具偏好进入取舍。** AgentScope / LangGraph、不同模型、采购 / 自研，都应以同任务 POC、维护能力、服务级别和退出成本决定。普通函数足够时，增加框架也可能是负担。
6. **从个人产出进入团队交付。** 难题与提效题在考责任边界、证据和沟通。应区分真实经历、教学假设与建议方案，不能照背本资料的示意数值当自己的上线成果。

回答可按“结论 → 前提 → 关键机制 → 一个具体例子 → 故障边界 → 如何验证”的顺序。没有做过某一规模时直说，并给出可执行的验证计划。

## 延伸题如何训练

60 道题不是简单改写题干。它们分别改变规模、并发、权限、版本、失败时序或成本约束。建议先给出自己的方案，再打开参考答案，检查：是否讲清不变量，是否遗漏失败分支，是否能设计一个区分原因的实验。数据库准备双会话 SQL；AI 准备请求、候选证据、工具和用量轨迹；SaaS 准备双租户回归与迁移时间线。

## 算法训练

现有 42 道 ACM 标准输入输出题，分为基础、进阶和挑战。每题有题意、格式、范围、样例与解释、算法依据、复杂度、提示和 Node 可直接提交的完整参考程序。原有 12 道迁移函数题也补齐输入语义和调用例子，合计 54 道算法挑战；此外保留 28 个基础工程实验。

| 题目 | 训练重点 | 级别 |
| --- | --- | --- |
| 区间账单求和 | 定义 prefix[i] 为前 i 个数之和，区间 [l,r] 等于 prefix[r]-prefix[l-1]。prefix[0]=0 消除从第 1 项开始的特判。负数不影响公式；逐查询扫描最坏 O(nq) 不满足规模。 | 入门 |
| 批量查找不小于目标的位置 | 维护半开区间 [l,r)，答案可能为 n。a[m]≥x 时 m 仍可能是答案，应保留左半；否则答案严格在右侧。最终 l+1 转成题目的 1-based 位置。不要命中后立即返回，重复值要求最左。 | 基础 |
| 仓库网格最少步数 | 无权图的 BFS 按距离递增扩展，第一次入队的距离就是最短距离。入队即标记可避免重复；队列用数组+头指针，避免反复 shift。DFS 能找到路径但不能用首次到达保证最短。 | 基础 |
| 预算内选择项目 | dp[c] 表示已经处理的项目在预算不超过 c 时的最优值。逆序枚举预算，确保 dp[c-w] 尚未使用当前项目；正序会变成可重复选的完全背包。初始化全零对应允许不选，不是必须恰好花完。 | 进阶 |
| 两份记录的最长公共子序列 | dp[i][j] 为两个前缀的 LCS 长度，相等时从对角+1，否则丢弃一侧末尾取最大。按行滚动，仅保留上一行和当前行。这里输出长度，若要实际序列还需回溯信息或其他恢复策略。 | 进阶 |
| 滚动监控窗口最大值 | 队列保存下标且对应值单调递减。新值淘汰左侧更小且更早过期的值，队首过期时弹出。每个下标最多进出一次，摊还 O(n)，不是每次维护都 O(1)。 | 进阶 |
| 仓储柱状图最大矩形 | 当遇到更矮柱时，被弹出的柱高的右边界确定为 i-1，左边界在弹栈后的栈顶之后。宽度为 i-left-1。末尾补零哨兵清栈；相等柱的处理要与边界公式一致。 | 进阶 |
| 动态连通关系查询 | 并查集用根代表连通分量，合并根并按大小连接，查询比较根。路径压缩加按大小合并获得近常数摊还代价。普通并查集不支持删边，不能将此方案直接用于动态删除。 | 基础 |
| 配送网络最短路线 | 非负边保证当前最小暂定距离可确定。使用小根堆避免每次 O(n) 找最小点；更新距离后入新堆项，取出时跳过过期项。负权图不满足证明前提，不能直接套本题。 | 进阶 |
| 最低成本连通所有机房 | Kruskal 按边权从小到大尝试，连接不同分量的边加入，否则形成环而跳过。割性质支持安全选择。n 个点连通需 n-1 条有效边；自环永不帮助连接，重边可正常参与排序。 | 进阶 |
| 账单修改与区间查询 | 静态前缀和每次更新需 O(n)，树状数组按 lowbit 管理若干区间，单点增加和前缀查询各 O(log n)。下标从 1 开始，i=0 更新会死循环；闭区间和仍用 prefix(r)-prefix(l-1)。 | 进阶 |
| 日志模式的全部匹配位置 | 前缀函数 pi[i] 表示到 i 为止的前缀中最长真前后缀长度。失配沿 pi 回退，不回退文本位置；匹配成功后也沿 pi 回退保留重叠。返回下标需从零基 i-m+1 转成一基 i-m+2。 | 进阶 |
| 同时进行的任务槽位 | 扫描线把开始记 +1、结束记 -1，同一时间先处理结束体现半开区间可复用。答案是最大同时活跃数，既是必要下界，也可通过空闲机器复用达到。闭区间版本的同时间规则不同。 | 基础 |
| 按顺序运输的最小载重 | 容量越大，需要天数不会更多，形成单调判定。给定容量按顺序尽量装满可最小化使用天数；二分第一个可行容量，下界最大单件、上界总重量。不能按重量重排，题目要求原顺序。 | 进阶 |
| 有向无环依赖中的路径数量 | 拓扑序保证处理 u 时其所有前驱已完成。dp[v] 累加 dp[u]，每次加法立即取模，值小于 2×模数避免精度问题。先拓扑再传播，与在一般有环图中数路径不同，后者可能有无限多走法。 | 进阶 |
| 通信树的最长距离 | 树上任意两点有唯一简单路径，从任意点找最远端点，再从该端点找最远距离得到直径。这个两次搜索结论依赖树结构，不能直接套一般图。用迭代 BFS 避免长链递归爆栈。 | 进阶 |
| 小规模巡检的最短闭环 | dp[mask][u] 表示从 1 出发访问集合 mask、末尾在 u 的最小费用。初态 mask=1,u=0；向未访问点转移，最后加回到 1 的费用。把过去压成集合与末尾足以决定未来，这是状态压缩成立的原因；n 大时指数复杂度不可扩展。 | 挑战 |
| 超大编号的递推计数 | 快速倍增同时求 (Fk,F(k+1))：F(2k)=Fk(2F(k+1)-Fk)，F(2k+1)=Fk²+F(k+1)²。乘积可超过 Number 安全范围，所以使用 BigInt，并修正减法模数。返回字符串避免输出 BigInt 的调试后缀。 | 挑战 |

浏览器使用 Worker 模拟同步 Node 输入输出，只支持 `require("fs" / "node:fs").readFileSync(0 / "/dev/stdin", "utf8")`、`console.log/info`、`process.stdout.write` 与诊断输出，不是完整 Node 环境。运行输入只展示结果，不记录通过；提交验证才运行题目用例并保存结果。判题忽略行尾空白和末尾空行，保留行内内容与行顺序，不做数字/字符串语义猜测。代码不会在后端执行。

## 排序、贪心与动态规划入门

从 `/learn?collection=algorithm-foundations` 开始，依次阅读读题与规模、排序入门、分治排序、贪心、动态规划起步、背包与区间状态 6 节资料。每节有中文机制解释、手推过程、错误反例、JavaScript 实验、补全练习和独立追问。

新增 24 道题按以下顺序练习；实验室可按算法分类和难度筛选：

| 路线 | 推荐练习顺序 | 重点 |
| --- | --- | --- |
| 排序 8 题 | 归并排序 → 合并有序数组 → 稳定记录排序 → 三色排序 → 相对排序 → 最大拼接数 → 逆序对 → 第 K 小 | 比较器、稳定性、边界、分治计数、三向划分；第 K 小参考实现平均 O(n)，最坏 O(n²) |
| 贪心 8 题 | 分饼干 → 会议选择 → 救生艇 → 气球射箭 → 最少跳跃 → 糖果 → 文件最优合并 → 删除数字 | 局部选择标准、交换论证、单调结构、不能套用的反例 |
| DP 8 题 | 爬楼梯 → 非相邻最大收益 → 最大子数组 → 障碍网格路径 → 等和划分 → 硬币组合 → 股票手续费 → 最长回文子序列 | 状态中文定义、转移完整性、初始化、迭代方向和空间压缩 |

先用样例手算，再用自定义输入调试，最后提交验证。42 道 ACM 每道都有 29 组实际提交测试：4 组固定边界 + 24 组固定种子随机小数据 + 1 组声明约束上限。随机数据用独立的子集／排列／路径枚举等算法生成预期；上限数据使用可推导答案检查规模与数值。每组最多 3 秒、整次最多 15 秒，执行进度可见，超时或停止不会记录通过。设备性能会影响计时，这不是严格隔离的竞赛评测系统。

回归测试复用同一生成器，验证全部参考程序；还验证“仅记住原四组答案”的错误实现会在扩展测试中失败。通过有限测试仍不等于正确性证明，应该同时解释不变量或转移为何覆盖所有合法方案。
