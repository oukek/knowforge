## 程序怎样一步一步执行
Python 源文件是一组按语法组织的语句，解释器读取并执行它们。表达式计算一个值，赋值把名字绑定到对象，函数调用执行一段可复用逻辑。先分清“求值”和“显示”：`1+2` 产生3，在脚本里却不会自动打印；交互解释器显示表达式结果，是交互环境提供的便利。

Python 用缩进表达代码块，不靠花括号。一个 if 或函数体中的多条语句必须处于一致缩进层级，惯例使用四个空格。缩进错误不是排版小问题，而是改变了程序结构。注释解释意图，不能替代语法上的代码块。
## 变量、类型与运算符从哪里开始读

赋值语句 `total = price * quantity` 要从右往左理解：先取出 price 和 quantity 指向的值，完成乘法，再把结果绑定到 total 这个名字。变量并不是预先固定类型的小盒子；同一个名字之后可以绑定到另一种对象，但频繁改变含义会增加阅读成本。`=` 是赋值，`==` 是比较，`!=` 是不相等，不能相互替换。

| 值的类型 | 例子 | 最先要理解的操作 |
| --- | --- | --- |
| int 整数 | 3、-2 | 加减乘、整除、余数；不把字符串当数字 |
| float 浮点数 | 0.5 | 近似表示实数，部分十进制数不能精确表示 |
| str 字符串 | "课程" | 拼接、切片、格式化；字符串本身不可原地修改 |
| bool 布尔值 | True、False | 比较产生结果，条件语句据此选择路径 |
| NoneType | None | 表示缺失等明确状态，不能盲目参与算术 |

`/` 表示普通除法，`//` 表示向下取整的商，`%` 表示余数，`**` 表示乘方。先乘除后加减；不确定优先级时用括号写出意图。`and`、`or` 有短路行为，而且返回的是其中一个操作数，不保证结果类型就是 bool。例如 `name or "匿名"` 会在 name 为空字符串时选用默认值；如果空字符串本来就是有效输入，这个简写就不适合。

## 从显示文本到一个返回结果的函数

print 是把信息写到输出流，return 是把值交还调用者。把业务计算写成返回值的函数，才能在网页接口、命令行或测试中复用同一规则。下面不读取键盘，也不依赖外部库，可以独立运行。

```python
def subtotal(price, quantity):
    if price < 0 or quantity < 0:
        raise ValueError("价格和数量不能为负数")
    return price * quantity

amount = subtotal(20, 3)
print("应付：", amount)
print(7 // 2, 7 % 2, 2 ** 3)
```

调用时参数20与3分别绑定到函数自己的 price 和 quantity；函数结束后结果60回到赋值位置。校验失败时抛异常，本次调用不会继续执行正常 return。后面的函数课会展开参数、作用域和异常传播；现在先把“输入→计算→返回→展示”这条关系读懂。

## 写一个完整可运行脚本
```python
name = "小林"
price = 20
quantity = 3
total = price * quantity
print(f"{name}需要支付{total}元")
print(type(total).__name__)
```
保存为 main.py，运行 python main.py。字符串使用引号，整数与字符串是不同类型；f-string 在花括号里求值并格式化。`"20" * 3` 会重复字符串，而不是计算60，所以来自 input、URL或JSON的数据应按契约转换并验证。
## 真值、None 与比较
None 表示没有提供或没有结果的常见哨兵，不等于0、空字符串或False。判断 None 用 is None；比较业务值通常用 ==。空容器在条件里为假，但如果业务要区分“未查询”和“查询结果为空”，仅写 if not value 会把两种状态混在一起。
```flow
阅读基础代码的路径
识别字面量与名字｜字符串、整数、布尔值、None
求值表达式｜先算右侧，再确定结果类型
建立或改变绑定｜名字指向对象
按缩进执行代码块｜分支、循环与函数各有边界
观察输出或返回值｜打印和返回不是同一件事
```
## 外部输入不能靠类型猜测
input() 返回字符串；int(text) 可能抛 ValueError。先写清允许格式和范围，再解析；不要用 eval 解释用户输入。浮点数不保证十进制金额精确，货币需要最小单位整数或合适 Decimal 规则。

练习把 quantity 改成0、字符串和负数，分别说明语法是否合法、结果类型是什么、业务是否允许。程序能运行与数据符合业务规则是两个层次。熟悉这些基础后，再进入容器、函数和对象模型，避免一开始就背框架术语。
