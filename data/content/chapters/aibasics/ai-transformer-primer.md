## 从具体问题认识Transformer 入门

一句话中的词需要结合其他位置才能解释。例如“我把书放进包里，它很重”中的“它”可能需要上下文消歧。Transformer 通过注意力等计算，让每个位置的表示吸收可见位置的信息，再经过多层变换形成更丰富的表示。

它不是一张关键词匹配表。输入向量、可学习矩阵、位置关系、掩码、前馈网络与归一化共同参与计算，注意力只是其中一个核心部分。

## 先看一个查询位置如何汇总信息

对每个输入位置，通过不同线性变换得到 Q、K、V。某个位置的 Q 与可见位置的 K 计算匹配分数，经缩放、掩码与 softmax 得到权重，再对对应 V 加权求和。Q/K 决定如何分配关注，V 提供被汇总的信息；多头允许在不同表示子空间进行这类计算。

因果掩码阻止生成任务的位置读取未来答案。训练时可以并行计算多个位置，但每个位置的可见范围仍受限制；否则模型会利用本不该知道的后续 token。位置编码或位置相关变换提供顺序信息，不能只把相同词集合当成相同句子。

注意力输出还经过残差、归一化与前馈等结构，逐层更新表示。最终生成模型把当前位置表示映射到词表候选分数。注意力权重不等于引用来源或因果解释，某个权重很大也不能直接证明输出事实由那句话可靠支持。

## 残差与前馈层怎样补充注意力

注意力把不同位置的信息按权重汇总，前馈网络则对每个位置的表示做非线性变换。残差将子层输入与其变换结果相加，让原信息保有直接传播路径，也有助于深层训练的梯度传播；归一化帮助控制数值尺度。不同架构对子层和归一化的排列并不完全相同。

因此看到注意力权重变化，只能解释这一步怎样分配信息，不能完整解释后续所有层如何产生答案。教学时先拆单头的小向量运算，再把多头、残差与前馈放回整体，避免把模型简化成一个 softmax。

## 顺序为什么需要表示

单纯对一组元素做内容匹配，不能自然区分所有语序。位置编码或位置相关注意力让模型利用顺序。绝对、相对或旋转位置方法有不同实现和外推特性，不应把训练时窗口以外的长度简单扩大配置就当作效果保证。

“狗追人”和“人追狗”词集合相同，关系不同。语言、代码和视频都涉及顺序与结构信息，表示方式和输入预处理应与模型训练约定一致。

## Encoder、decoder 和混合结构

Encoder 常用于双向表示，适合分类和表示任务；自回归 decoder 通过因果可见性逐步生成；encoder-decoder 先编码输入，再由 decoder 在生成时利用输入表示。名称指结构族，不表示每个具体产品一定能做某项任务。

| 结构 | 典型可见性 | 适合理解的任务 |
|---|---|---|
| Encoder | 输入中可看左右上下文 | 表示、分类、标注 |
| Decoder-only | 每步看已有前缀 | 文本和代码生成 |
| Encoder-decoder | 编码输入加因果输出 | 条件序列转换 |

微调目标、解码策略和数据也影响能力，不能仅凭结构名称给出完整性能结论。

## 误区与下一步

不要把注意力权重当作引用或因果解释；不要认为 decoder 生成时可以访问尚未生成的正确答案；不要把 KV Cache 与模型参数或聊天摘要混为一谈。理解结构后再学习 prefill/decode、缓存大小和推理调度。

验证时从小矩阵手工检查可见性、padding、位置偏移和缓存长度，再与框架实现对照。面试能画出输入、QKV、加权汇总、前馈和下一 token 输出，通常比背一串模型缩写更能证明理解。

## 把机制放到一条完整路径中

```flow
Transformer 局部计算
输入表示｜token 向量结合位置信息
QKV 匹配｜计算可见位置之间的注意分数
加权汇总｜掩码与归一化后组合 V
层间变换｜残差前馈等继续更新表示
```

## 配套代码：Transformer 入门：QKV、位置、掩码与三类结构

下面复用本课的确定性机制实验，只表达所讨论的局部关系，不等于真实宿主、数据库或模型服务。



```javascript
function causalMask(n) {
  return Array.from({ length: n }, (_, query) =>
    Array.from({ length: n }, (_, key) => (key <= query ? 0 : "-inf")),
  );
}
const mask = causalMask(4);
console.log(mask[1]);
console.log(mask[3]);
console.log({ pastVisible: mask[2][1] === 0, futureVisible: mask[1][2] === 0 });
```

字符串 -inf 只是可读的教学标记；真实实现使用张量掩码或内核可见性规则。此例不实现完整 Transformer。
