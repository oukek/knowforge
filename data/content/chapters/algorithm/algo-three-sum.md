## 从具体问题认识三数之和、排序与去重

三数之和通常要求从数组中选择三个不同位置，使三个数相加为零，并返回不重复的数值三元组。不同位置可以保存相同值，因此 [0,0,0] 合法，但只有一个 0 时不能重复使用同一个位置凑三次。

对 [-1,0,1,2,-1,-4]，答案包含 [-1,-1,2] 与 [-1,0,1]。结果去重指三元组的数值组合不重复，不是先把输入中的重复数全部删除。

## 排序怎样让双指针有方向

排序后固定第一个位置 i，在它右边用 l 与 r 寻找另外两个数。若总和小于零，增大左侧值可能让和增大，因此 l 向右；若总和大于零，减小右侧值可能让和减小，因此 r 向左。这种排除一批候选的依据来自有序性。

找到零和后记录三元组，并跳过左右相同值；外层固定值也跳过与前一个相同的情况。去重位置不同：外层避免同一个首值重复搜索，内层避免同一首值下重复输出同样一对。指针始终满足 i<l<r，保证使用不同位置。

外层 O(n)，每次内层两个指针总共移动 O(n)，主复杂度 O(n²)，排序通常不改变这个主阶。若题目要求原数组不变，先复制再排序。若数值可能超过语言的安全整数范围，还需选择相应数值表示，不能只关注下标正确。

## 把机制放到一条完整路径中

```flow
三数之和
排序｜建立值随下标单调变化的条件
固定首项｜跳过重复首值
双指针搜索｜按总和大小排除候选
记录去重｜找到解后越过相同左右值
```

## 配套代码：把机制变成可运行函数

下面代码在课内JavaScript运行区执行；需要DOM、Node或平台SDK的真实集成，应按正文的运行边界另行验证。

排序和双指针去重，不修改输入数组。

```javascript
function threeSum(nums) {
  const a=[...nums].sort((x,y)=>x-y),out=[];
  for(let i=0;i<a.length-2;i++){if(i&&a[i]===a[i-1])continue;let l=i+1,r=a.length-1;while(l<r){const sum=a[i]+a[l]+a[r];if(sum<0)l++;else if(sum>0)r--;else{out.push([a[i],a[l],a[r]]);const x=a[l],y=a[r];while(l<r&&a[l]===x)l++;while(l<r&&a[r]===y)r--}}}
  return out;
}


const source=[-1,0,1,2,-1,-4];
console.log(threeSum(source));
console.log(source);
console.log(threeSum([0,0,0,0]));
```

固定点和两端都去重，结果不会重复；先复制再排序保留调用方输入。二重扫描的最坏时间为 O(n²)，不是线性。

## 从示例走向实际使用

手推排序后的 [-4,-1,-1,0,1,2]，特别观察首值 -1 的那一轮。测试全零、长度不足三、没有解和多组重复值。

不要用 JSON 字符串集合补救所有重复输出后就忽略算法结构；理解每层去重，才能迁移到四数之和等问题并控制额外开销。
