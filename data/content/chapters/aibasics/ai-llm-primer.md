## 从具体问题认识LLM 是什么

输入“今天的课程讲解了”，语言模型会根据已有文本计算后续片段的候选分布，再逐步选择并继续生成。LLM 的语言能力建立在大量数据中学到的模式上，但它输出的是基于条件的候选序列，不是从一个保证正确的答案数据库中取出记录。

这解释了两种同时存在的现象：模型可以在没见过的具体提问上组织有用答案，也可能把不确定内容表达得非常流畅。理解生成机制，有助于正确使用它的能力和限制。

## 参数中的规律与当前上下文中的事实

训练把大量样本中的统计规律压缩到参数中，推理时通常不修改这些参数，而是利用当前输入计算输出。你在一次对话里告诉模型项目端口是 16666，它可以在该上下文中使用这个事实，但不等于所有后续用户调用的模型参数都被更新。

自回归生成把已生成 token 接回输入条件，重复计算下一个候选。某一步选错实体或条件，后续内容可能围绕错误继续展开。高概率说明模型偏好某种续写，不直接说明世界事实正确；要求精确业务数据时，应提供可靠来源或调用工具。

聊天产品通常额外组织系统指令、历史、检索和工具。用户看到的“模型能查文件”可能由宿主应用执行检索，再把结果送给模型。评估时应区分裸模型、带工具的应用与具体提示配置，否则不同系统的表现无法公平比较。

## LLM 的完整名称与基本任务

LLM 是 Large Language Model，大语言模型。它通常使用大量语言数据训练，学习在上下文条件下预测后续 token 的分布，并能通过适配完成问答、摘要、代码和信息抽取等任务。“大”没有适用于所有年代和架构的固定参数门槛，不能只凭某个 B 数断定质量。

对自回归生成，可将一段序列概率写为各位置条件概率的连乘。每生成一个 token 就把它接回上下文，再进行下一步。这里的概率描述模型对序列的偏好，不直接等于答案事实正确率或用户任务完成率。

## 从模型到聊天产品

基座模型主要学习一般语言和数据规律，指令适配让其更容易按任务要求回答；推理型能力可能通过不同训练和推理时策略形成。聊天产品还包含消息组织、工具、文件处理、搜索、风控和用户界面。产品能联网查天气，不意味着模型参数在每次聊天后自动更新天气。

| 名称 | 讨论对象 | 需要核实 |
|---|---|---|
| 基座模型 | 结构与参数 | 训练目标及使用许可 |
| 指令模型 | 对任务的适配行为 | 输入模板和评估表现 |
| 模型 API | 托管推理接口 | 版本、协议和限制 |
| 聊天应用 | 端到端产品 | 工具、权限和数据策略 |

同名系列的不同版本、量化和部署设置也会有差异，应记录实际版本，避免只说“用了某大模型”。

## 为什么能做很多任务，又为什么会错

文本、代码和任务示例共享许多可学习模式，较丰富的预训练加任务适配可支持广泛能力。但模型仍可能缺少知识、误用条件、对输入歧义作错误补全，或在检索证据错误时生成看似可信的解释。表达自然不是事实担保。

要处理实时或私有知识，通常通过上下文、检索或工具提供事实；精确金额由程序计算；高风险动作由规则和权限服务检查。不能把“提示模型不要编造”当成完整方案，也不能把所有错误简单归为随机采样。

## 如何验证理解

用自己的话解释 token、参数、上下文与工具的区别：参数来自训练；上下文是本次推理提供的信息；工具由宿主执行；输出是候选内容或行动。随后给一个例子说明模型为何不能凭自身回答当前库存。

学习 LLM 不需要先记住所有模型品牌。先掌握生成机制、输入契约和失败边界，再用自己的任务集比较能力、费用和时延。研究某个具体模型时阅读其模型卡、许可及实际版本文档。

## 配套代码：LLM 是什么：语言概率、能力与能力边界

下面代码在课内Python运行区执行；浏览器环境与本机CPython的网络、文件和原生扩展能力不同。



```python
import math

def sequence_stats(probabilities):
    if not probabilities or any(not 0 < p <= 1 for p in probabilities):
        raise ValueError('probabilities must be in (0,1]')
    return round(math.prod(probabilities), 4), round(-sum(math.log(p) for p in probabilities), 4)

print(sequence_stats([0.5,0.5]))
print(sequence_stats([0.5,0.5,0.5,0.5]))
print('token probability is not factual correctness')
```

长度增加改变序列概率尺度。负对数可以便于计算，但这些数不是事实置信度，也不是来自真实模型的概率。
