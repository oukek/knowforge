## 从具体问题认识预训练、SFT 与偏好对齐

模型训练可能包含多个阶段，各阶段的目标不同。预训练学习广泛的数据规律，监督微调通过输入与期望输出样本塑造任务行为，偏好优化利用更好与更差回答等反馈调整选择倾向。它们不是简单按时间排列就一定全部使用的固定流水线。

例如一个模型会续写文章，却不善于按指定 JSON 格式抽取信息，可能需要任务适配；若缺少最新公司政策，首先要解决事实来源，而不是只调整回答风格。

## 学习目标与数据格式必须对应

预训练目标常围绕预测数据中被隐藏或后续的内容，具体取决于模型结构。监督微调样本提供任务输入和目标输出，模型学习怎样按示范完成任务。数据中的错误、含糊规则和格式不一致也会被学习，所以数量不是唯一质量指标。

偏好数据比较同一任务下不同候选的相对表现，可用于训练奖励或直接优化偏好目标。偏好更高不自动代表事实更真，标注者可能偏爱冗长、自信或迎合的答案。需要把事实、帮助性、格式与安全等评价维度拆清，并监控优化后的副作用。

LoRA 等参数高效方法描述如何更新部分参数表示，量化描述数值表示方式，二者与训练阶段属于不同分类轴。可以在某种训练阶段采用参数高效适配，但不能把 LoRA 与 SFT 当作二选一的同层概念。

## 先按学习目标分阶段

预训练从大规模数据学习一般模式；监督微调 SFT 用输入与期望输出训练特定行为；偏好对齐使用比较或奖励信号调整回答倾向。阶段可以迭代组合，并非每个模型都使用完全相同流水线。了解一个具体模型时应阅读训练说明，不能凭“Chat”后缀推断全部实现。

预训练不等于只背事实，SFT 也不等于给模型安装一个数据库。任务能力、知识、风格和遵循约束会相互影响，最终效果必须在实际任务上测量。

## 数据格式决定能学什么

SFT 的最小单元是任务输入与目标输出；偏好对是同一输入下的 chosen/rejected。错误标注、缺少必要上下文或不一致偏好会把问题带入训练。不能用模型更喜欢自己的回答当作客观正确性。

| 方式 | 主要信号 | 示例 |
|---|---|---|
| 自监督预训练 | 从数据构造预测目标 | 给前缀预测后续 token |
| SFT | 期望行为示例 | 工单输入与正确分类 |
| 偏好学习 | 回答比较或奖励 | 同题有依据回答优于编造 |

RLHF 是一类基于人类反馈的对齐流程，DPO 是偏好优化方法之一，不能把所有偏好学习都称为同一个算法。

## LoRA、全量更新与量化在哪一层

全量微调更新大量原参数；LoRA 用低秩增量降低可训练参数量，是更新参数化方式，可与 SFT 等目标组合。量化改变数值表示或执行精度，关注内存与计算取舍，不等于训练目标。低比特基座配适配器训练也是组合方案，不是术语互相替代。

如果企业政策每天变化，训练不一定是合适知识更新通道。检索和工具更容易保留来源、版本、授权与删除能力；训练可能适合更稳定的格式和行为模式。先有基线和数据，再决定是否值得训练。

## PPO、GRPO 与推导输出的进一步区分

PPO 类方法通过特定优化目标抑制破坏性更新，裁剪目标不等于所有参数变化都有严格上界。GRPO 常为同一问题生成一组候选，用相对奖励构造训练信号；具体优势归一化、参考策略与 KL 配置随实现而异。它们是训练方法，不是让线上工具无限自主运行的许可。

CoT 推导监督、最终答案展示和推理时计算预算也需区分。训练中提供推导样本，不意味着上线隐藏推导文本后质量必然不变。固定基座、数据与预算做持出评估，审计主要记录可观察工具、证据和验证结果。

## 把机制放到一条完整路径中

```flow
训练目标选择
诊断能力缺口｜区分知识行为格式与偏好
准备对应数据｜文本示范或偏好比较
执行适配｜选择更新范围与优化方法
独立评估｜检查目标收益和能力回归
```

## 配套代码：预训练、SFT 与偏好对齐：模型怎样获得不同能力

下面代码在课内Python运行区执行；浏览器环境与本机CPython的网络、文件和原生扩展能力不同。



```python
def valid_pair(row):
    keys=('prompt','chosen','rejected')
    return all(isinstance(row.get(k),str) and row[k].strip() for k in keys) and row['chosen']!=row['rejected']

rows=[dict(prompt='问题',chosen='有依据',rejected='编造'),
      dict(prompt='问题',chosen='同一句',rejected='同一句'),
      dict(prompt='',chosen='A',rejected='B')]
print([bool(valid_pair(r)) for r in rows])
print('LoRA = parameterization; SFT = objective/data')
```

结构检查不判断偏好标签对错。LoRA 与 SFT 可以组合，它们分别回答怎样更新参数与用什么目标和数据学习。

## 从示例走向实际使用

先把目标失败类型写清，再决定数据与训练方式。用独立评估集验证改进，并保留基础能力回归测试，避免某个任务提高但其他重要能力下降。

本课偏好对校验只检查数据结构，不证明偏好标签正确。实际数据建设需要去重、来源治理、冲突检查和人工抽样。
