## 从具体问题认识合并区间与边界语义

区间用起点与终点表示一段连续范围，例如预约时间或覆盖范围。合并区间要求把有重叠的部分表示成更少的区间，同时保持覆盖集合不变。它与“选择最多不冲突区间”不同，后者会舍弃区间，前者不能丢失覆盖。

[1,3] 与 [2,6] 合并成 [1,6]，因为中间没有断开。端点相等是否算相交，则取决于题目采用闭区间还是半开区间，以及要求合并相交还是合并连续覆盖。

## 按起点排序后只需看最后一段

先按起点升序排列。处理当前区间时，之前结果已经有序且彼此分离；当前区间若与结果最后一段重叠，就扩展最后终点到两者最大值，否则追加新段。无需回头检查更早区间，因为它们的终点已经位于最后一段之前。

闭区间 [1,2] 与 [2,3] 共享端点，可以按相交合并；半开预约 [1,2) 与 [2,3) 不冲突，但若任务是压缩连续覆盖表示，也可以按另一个明确规则合并。关键是先写清语义，再选择 < 或 <=，不能把比较符当随意细节。

排序使时间通常为 O(n log n)，扫描 O(n)。若直接修改输入区间数组，调用者可能受到影响；示例先复制再排序。空输入、包含关系与相同起点都应处理，例如 [1,10] 包含 [2,3] 时，不能把终点错误缩短为 3。

## 把机制放到一条完整路径中

```flow
合并覆盖区间
定义端点｜明确相交与连续的规则
起点排序｜让待处理区间依次靠右
比较末段｜重叠则扩展否则追加
保持覆盖｜验证无遗漏且无重复区间
```

## 配套代码：把机制变成可运行函数

下面代码在课内JavaScript运行区执行；需要DOM、Node或平台SDK的真实集成，应按正文的运行边界另行验证。

闭区间端点相接也合并；和半开会议区间约定不同。

```javascript
function mergeIntervals(intervals) {
  const sorted=intervals.map(x=>[...x]).sort((a,b)=>a[0]-b[0]),out=[];
  for(const current of sorted){const prev=out[out.length-1];if(prev&&current[0]<=prev[1])prev[1]=Math.max(prev[1],current[1]);else out.push(current)}
  return out;
}


console.log(mergeIntervals([[1,3],[2,6],[8,10]]));
console.log(mergeIntervals([[1,2],[2,3]]));
console.log(mergeIntervals([]));
```

本题使用闭区间与 <= 合并，因此 [1,2] 与 [2,3] 相接也合并。半开区间的冲突检测不能直接照搬条件，必须先确定业务契约。

## 从示例走向实际使用

为每道区间题先写端点规则：时间段是否允许首尾相接、空区间是否合法、起点是否保证不大于终点。算法相似但契约不同，常见错误就藏在这里。

测试重叠链 [1,3],[2,4],[4,6]，确认一次扩展后的终点继续参与后续合并。最终结果应有序、互不重叠，且覆盖与输入一致。
