## 从具体问题认识意图识别

意图识别判断用户当前想完成哪类任务，例如查订单、申请退款或学习知识。它决定进入哪条流程，但不决定用户是否有权执行该操作。识别成退款，只意味着下一步检查退款条件。

一句话可能包含多个意图，也可能信息不足。例如“这个不要了”缺少对象和动作范围，强行选一个最高分分类容易导致错误操作。

## 方法组合与不确定性出口

规则适合明确命令和高精度条件，分类器适合稳定标签与足够标注数据，向量路由适合语义相似匹配，LLM 可以处理复杂上下文并输出结构。不同方法的成本、维护与可解释性不同，通常需要组合而非争论唯一最优。

先用低成本规则处理确定情况，再让分类或模型处理其余输入。最高分过低、前两名接近、多意图冲突或缺关键参数时转澄清。阈值需要用真实验证集校准，分数未校准时不能直接称为正确概率。

高风险动作即便识别明确，也必须验证身份、资源和当前条件，并按产品规则确认。记录误路由矩阵，观察哪些类别经常互相混淆，必要时调整标签定义，而不只是提高阈值。

## 意图和权限不是一回事

意图是用户想完成的任务，例如查询订单、申请退款或解释政策；实体是订单号、时间、金额等参数；授权是用户是否能执行。识别出“退款”不能证明有退款权限，缺少关键实体也不能凭模型猜测执行。多意图、否定、引用与纠正都可能改变任务，例如“不要退款，先查规则”。

## 可以选择哪些方法

稳定关键词和结构化入口可用规则，快且可解释但覆盖有限；有标注数据时用传统/轻量分类器，推理稳定但需要维护标签与漂移监控；embedding 与原型样本做语义路由适合扩展，分数却不天然是概率；LLM 结构化分类可处理复杂上下文，但有成本、延迟、格式错误与提示注入风险。

## 一个可落地的组合

优先使用 UI 明确动作与高精度规则，再对剩余请求做语义/分类路由，低置信或高风险交给受约束模型复核或直接澄清。结果包含 intent、entities、uncertainty 与 reasonCode，标签限定白名单，未知输出进入澄清。读取会话上下文解决“那笔”“还是算了”，但不要把过期意图沿用到新主题。

高风险动作先验证实体与权限并展示影响，模型自报 0.99 不能直接作为已校准概率。阈值由验证集上风险代价确定，可按不同意图区分拒识与误路由损失。多意图任务可拆成明确子步骤，不能让分类器决定所有执行顺序与副作用。

## 数据与评估怎样做

建立标注规范，包含边界、闲聊、超出范围、多意图、否定和对抗输入。按时间/用户分割，避免同一句模板进入训练和测试。看每类 precision/recall、混淆矩阵、拒识率、覆盖率与端到端误操作；总体 accuracy 很高仍可能把少量退款全分错。线上漂移经脱敏回流并人工复核。

## 如何回答“你用的哪个”

如实说明项目的标签数、样本量、延迟和误操作成本，以及为什么选当前组合。没有实际项目时给出建议方案而非伪造上线经验。更换方案应通过固定样本对比漏识别、误路由、成本和人工处理量，而不是因为某个框架集成方便。

## 把机制放到一条完整路径中

```flow
意图路由
收集上下文｜保留当前目标和必要指代
候选识别｜规则分类语义或模型组合
处理不确定｜低分冲突缺参数时澄清
进入流程｜独立执行授权与业务校验
```

## 配套代码：意图识别：规则、分类、语义路由与澄清

下面代码在课内JavaScript运行区执行；需要DOM、Node或平台SDK的真实集成，应按正文的运行边界另行验证。

使用本地 JavaScript 模型验证关键不变量；不调用真实数据库、模型或生产服务。实验简化之处与真实系统步骤见正文。

```javascript
function route(candidates,highRisk=false) {
 const [first,second] = [...candidates].sort((a,b)=>b.score-a.score);
 if(first.score<0.8 || first.score-(second?.score||0)<0.15) return 'clarify';
 return highRisk ? 'confirm:'+first.intent : first.intent;
}
console.log(route([{intent:'search',score:0.9},{intent:'refund',score:0.85}]));
console.log(route([{intent:'refund',score:0.95},{intent:'search',score:0.3}],true));
```

本段程序用于把状态、条件和数据之间的关系写清；真实实现仍需上文介绍的资源、权限与失败协议。

## 从示例走向实际使用

用短句、口语、否定、多轮指代、多意图和越界请求评估。比较自动完成率与误操作率，澄清率高不一定差，要看是否减少错误并保持体验。

课内 0.8 与 0.15 仅是演示阈值，不是可直接用于所有模型的经验标准。空候选也需要生产实现明确处理。
