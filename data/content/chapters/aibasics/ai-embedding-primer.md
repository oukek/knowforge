## 从具体问题认识Embedding 是什么

Embedding 把文本、图片或其他对象映射成一组数字，使某些相似关系能够通过向量运算比较。它不是给每篇文章随便分配一个编号，而是通过训练让表示对特定任务有用。

例如“如何取消订单”与“订单撤销流程”词面不同，但一个适合检索的模型可能把它们映射到相近方向。相近只说明表示空间中的匹配程度，不直接证明两段内容事实相同或权限相同。

## 向量相似与检索相关性

向量有维度，每一维是数值特征，通常不能简单解释为一个固定人类概念。余弦相似度比较方向，计算为点积除以两个向量长度；零向量需要单独处理。若所有向量已归一化，点积与余弦的排序关系会简化，但不能在未确认前混用距离度量。

查询与文档必须使用兼容的模型、版本和预处理方式。同为 1024 维并不表示两个模型的空间一致，把旧文档向量与新查询向量混用可能让距离失去意义。某些模型还区分 query 与 document 输入模板，需要遵循训练约定。

检索质量不只由向量决定。原文切分、标题、语言、权限过滤与重排都会改变结果。缩写、编号和精确实体可能更适合词项检索，因此混合检索常用于补充语义向量的弱点。阈值也需要从具体数据校准，不能把相似度 0.8 当成通用正确率。

## 用向量表示输入的意义

**向量可以理解成一组用于比较的数字坐标。** 把“如何申请退款”和“退款申请步骤”转成检索向量后，合适的模型可能让它们比“今日天气”更接近，从而在用词不完全相同时找到相关资料。

这种接近只表示模型在其向量空间里判断两段内容相似，不保证答案正确、语义完全等价或用户有权访问。向量由具体模型产生，替换模型或预处理方式后需要重新评估索引与相似度，不能只凭维数相同就混用。

例如两个词语的相似度高，并不代表一段资料能支持某个退款金额；系统仍需检查原文、适用条件和用户权限。

Embedding 把离散对象或文本等输入映射到连续向量，使模型能在数值空间学习关系。向量维度是坐标数量，不是知识点数量，也不能通常把某一维直接解释成“退款程度”。表示质量来自训练目标和数据，不是维度越高就一定更懂业务。

Token embedding、上下文中的 token 隐藏状态与整句检索 embedding 是不同对象。用生成模型某层向量随便平均，不一定能替代为检索训练的句向量模型。实际使用需核对 pooling、指令前缀和长度截断约定。

## 余弦相似度的数学直觉

对非零向量 a、b，cosine 等于点积除以两者长度乘积，衡量方向接近程度。把向量乘正数不改变余弦，但会改变未归一化点积。两个向量都作单位归一化后，点积等于余弦。

| 相似度 | 观察重点 | 易错处 |
|---|---|---|
| 点积 | 方向与长度共同影响 | 未归一化时长向量可能占优 |
| 余弦 | 相对方向 | 零向量无定义 |
| 欧氏距离 | 坐标差 | 是否归一化影响排序 |

不同模型的分数分布不同，0.8 不能成为跨模型通用的“答案可靠”阈值。

## 检索时还缺什么

相似不等于相关，更不等于支持结论。查询“允许退款吗”与“禁止退款政策”可能语义接近，否定和适用范围仍需判断。产品型号、精确编号和日期还适合关键词等方法，与向量检索融合后再评估。

索引应记录 embedding 模型、维度、规范化方式、语料和权限元数据。不同模型即使维度相同，也不代表位于同一空间；升级时不能把旧文档向量与新查询向量直接混用。重建或双索引切换需要验收覆盖和回滚。

## 面试时应能解释的边界

说清楚 embedding 解决的是表示问题，向量数据库解决存储和近邻查询，RAG 将检索证据纳入生成。三个词不能互相替代。向量库支持某种索引，也不自动提供正确的切片、授权和事实核验。

准备一个反例：高度相似的旧版政策与当前规则相反。用版本与适用范围过滤，再评价证据支持，而不是只提高相似度阈值。这样才能把数学概念接到应用正确性上。

## 把机制放到一条完整路径中

```flow
Embedding 检索
准备输入｜清洗文本并保留来源与权限
生成向量｜固定模型版本与输入模板
计算候选｜按相容距离查找近邻
验证相关｜结合过滤重排与真实标注评估
```

## 配套代码：Embedding 是什么：向量、余弦相似度与模型版本

下面代码在课内Python运行区执行；浏览器环境与本机CPython的网络、文件和原生扩展能力不同。



```python
import math

def cosine(a,b):
    if len(a)!=len(b) or not a:
        raise ValueError('dimension mismatch')
    na=math.sqrt(sum(x*x for x in a)); nb=math.sqrt(sum(x*x for x in b))
    if not na or not nb:
        raise ValueError('zero vector')
    return sum(x*y for x,y in zip(a,b))/(na*nb)

print(cosine([1,0],[2,0]))
print(cosine([1,0],[0,1]))
v=[3,4]; n=math.sqrt(sum(x*x for x in v))
print([x/n for x in v])
try: cosine([0,0],[1,0])
except ValueError as e: print(str(e))
```

手工向量验证方向、归一化和零向量边界；没有调用真实 embedding 服务，不能用这些数作为文本相关性阈值。

## 从示例走向实际使用

先建立少量相关、不相关和容易混淆的查询文档对，观察排序而不是只看某个分数。模型替换时重建或迁移索引，并与旧版本在相同评估集上比较。

课内手工向量用于理解方向与尺度，真实语义向量需由训练模型生成。不要把二维示意图当作高维语义空间的完整解释。
