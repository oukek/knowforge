## 先问窗口能否单调移动
滑动窗口能达到线性时间，不是因为代码里有两个指针，而是每个指针只向前移动 O(n) 次。要证明何时可以安全丢弃左侧信息。对全部非负数组求和至少达到 k，扩张窗口不会降低和；若允许负数，这个单调关系就不成立，不能照搬“和大就缩小”的规则。

子数组和等于 k 时，用 prefix[j]-prefix[i]=k 转成查找历史前缀和 prefix[j]-k 出现了多少次。频次数组/Map 在处理当前位置之前先查询，再记录当前前缀，否则 k=0 会把空区间误算进去。初始前缀和 0 出现一次，用于表示从数组开头开始的区间。
## 最长无重复子串
维护窗口内每个字符的最后位置。遇到重复字符时 left=max(left,last+1)，不能直接把 left 移回之前的位置。JavaScript 字符串索引基于 UTF-16 code unit；若题目按 Unicode 码点计字符，先 Array.from，若按用户可感知字素簇则需明确分词策略，不能混用。本站题目会声明采用码点。
## 可运行的前缀频次实现
```javascript
function countSubarrays(nums,k){
  const counts=new Map([[0,1]]);
  let prefix=0,answer=0;
  for(const value of nums){
    prefix+=value;
    answer+=counts.get(prefix-k)??0;
    counts.set(prefix,(counts.get(prefix)??0)+1);
  }
  return answer;
}
console.log(countSubarrays([1,-1,1],1)); // 3
```
每一步的 counts 只包含当前位置以前的前缀，正是“不计算空区间”的不变量。空间最坏 O(n)，并非所有双指针类题都能做到 O(1) 空间。
## 最小覆盖窗口为何要记录频次
目标为 AABC 时，需要两个 A，不能只用 Set 判断是否出现。维护 required 与 have，统计已经满足数量要求的字符类别；扩张至全部满足后，尽量移动 left 缩短窗口，并在移出某字符导致不足时停止收缩。只在需求阈值被跨越时修改 formed，避免把出现过多次的字符重复计数。
## 反例与验收
测试空输入、目标不可能覆盖、重复需求、全相同字符、负数与零、emoji 码点。每次更新窗口后验证 have 对应的确实是 [left,right] 区间。复杂度证明要说明内层 while 在整个执行中总共移动 left 至多 n 次；不能看到嵌套循环就断定 O(n²)，也不能只声称“双指针所以 O(n)”。

还要把编码转换算进实现成本：Array.from(text) 会产生 O(n) 码点数组，不能只统计频次表然后宣称整个实现只用 O(字符种类) 空间。最长无重复长度可以用 for...of 加码点计数避免保存整串数组；最小覆盖若要按下标取子串，则要明确如何维护 UTF-16 偏移。编辑距离的滚动 DP 行可以缩到 O(min(m,n))，但若先复制两条字符串成码点数组，总额外空间仍为 O(m+n)。算法模型和具体实现的复杂度应分开说明。
